# Формат проекта дома `house/1`

Файл `*.house.json` — единственный источник дома: из него приложение строит геометрию, свет,
участок и точки презентации. Его пишет ИИ через MCP. Примеры: `Assets/StreamingAssets/Samples/`
(`46-96.house.json` — двухэтажный дом с плоской кровлей, `barnhouse.house.json` — одноэтажный барнхаус).

## Соглашения

- Единицы — метры и градусы.
- Мир: X вправо, Y вверх (0 = уровень земли), Z «на север». Точка на плане — `[x, z]`, в пространстве — `[x, y, z]`.
- Повороты — вокруг вертикали, в градусах, как по компасу: 0 → +Z (север), 90 → +X (восток), 180 → −Z (юг), 270 → −X (запад).

  | где | что означает угол |
  |---|---|
  | `items[].rotation` | куда смотрит перед предмета (сиденье, дверцы, изножье кровати) |
  | `stairs[].direction` | куда идёт (поднимается) первый марш |
  | `roofs[].rotation` | gable/hip: конёк идёт поперёк этого направления (0 → конёк запад–восток); shed: куда поднимается скат (высокая сторона) |
  | `views[].yaw` (walk) и `house_render` walk | куда смотрит камера |
  | `house_render` orbit `yaw` | **откуда** смотрим: 0 — камера на юге и смотрит на север, 90 — камера на западе |
- Не считай геометрию в уме: `house_inspect` показывает построенный дом в числах (верх стен, проёмы в координатах, карниз и
  конёк крыши, габарит и проём лестницы, размеры предметов), `house_catalog` — реальные размеры моделей.
- После каждой правки ответ содержит `issues` — ошибки документа и проверки построенного дома (мебель в стене или в проходе,
  дверь в обрыв, проём выше стены или в углу, крыша сквозь комнату, лестница в стену, комната без крыши). Каждое сообщение
  говорит, что поменять, — исправляй сразу.
- Всё необязательное имеет разумные значения по умолчанию. Короткий документ — нормально.
- Имена материалов не зависят от регистра и `_`: `oak_light` = `OakLight`.

## Корень

| поле | что |
|---|---|
| `format` | `"house/1"` |
| `meta` | `name`, `description`, `author`, `created`, `modified` |
| `site` | участок — правь инструментом `house_site` (см. «Участок»). `landscape`: `natural` (участок с рельефом, газоном, дорожками, площадками, деревьями — **по умолчанию у новых домов**) · `garden` (простой газон, отмостка, дорожка, деревья) · `lawn` · `none` · `catalog4696`; `sunAzimuth` (откуда светит солнце, 0 = север, по часовой; 180 = юг), `sunElevation` |
| `levels` | этажи |
| `walls`, `openings` | стены и проёмы |
| `rooms` | комнаты (полы, потолки, свет, пробы отражений) |
| `roofs`, `stairs`, `lifts`, `elements` | крыши, лестницы, лифты, архитектурные элементы |
| `items`, `lights`, `views` | предметы каталога, источники света, точки презентации |

## Этажи — `levels`

`{ "id": "ground", "name": "1 этаж", "elevation": 0.3, "height": 2.8, "slab": 0.3 }`

- `elevation` — отметка чистого пола над землёй; `height` — высота до потолка; `slab` — толщина перекрытия **под** этим этажом.
- Этаж выше должен начинаться не ниже `elevation + height + slab` нижнего (иначе ошибка валидатора).

### Подвал (цокольный этаж)

Подвал — обычный этаж с **отрицательной** `elevation` (пол ниже земли), например при первом этаже на отметке 0.6:

```json
{ "id": "basement", "name": "Подвал", "elevation": -2.2, "height": 2.5, "slab": 0.3 }
```

- Высоты сходятся как у любых этажей: `-2.2 + 2.5 + 0.3 (slab первого этажа) = 0.6` — отметка пола первого этажа.
- Наружные стены подвала — **свои**: `house_exterior_walls` с `level: "basement"` и другим `prefix` (например `b`). Они сами
  уходят до плиты пола подвала и поднимаются до низа перекрытия первого этажа; над землёй виден цоколь. Земля, газон и
  рельеф внутри контура подвала вынимаются сами — снаружи их не видно, изнутри не мешают.
- Окна подвала ставь под потолок (`sill` ≈ `height − высота окна − 0.1`): если низ окна ниже земли, перед ним сам
  строится бетонный **приямок** (световой колодец) с гравием на дне.
- Наружная дверь подвала (`door`, `entryDoor`) ниже земли получает сама **спуск**: площадку перед дверью, бетонные
  ступени к земле и ограждения по бокам. Длина спуска ≈ 1.2 + 0.3 × число ступеней — оставь перед дверью свободное место.
- Лестница из подвала — обычная (`from: "basement"`, `to` — этаж выше); проём в перекрытии вырежется сам.
- План подвала: `house_render` `mode: "plan"` с `level` подвала; `walk` в подвале — с `level` подвала. Без `level`
  рендеры и вход в дом берутся с этажа на уровне земли, а не с подвала.
- Проверка предупредит: подвал без своих наружных стен, окно глубже 1.6 м под землёй, слишком длинный спуск к двери,
  лестница поперёк двери.

## Стены — `walls`

```json
{ "id": "front", "level": "ground", "a": [0, 0], "b": [12, 0], "outside": "wood", "plinth": 0.45 }
{ "id": "p1", "level": "ground", "kind": "interior", "a": [8, 0.4], "b": [8, 8.2] }
```

- Прямой отрезок `a → b` под любым углом.
- `kind`: `exterior` (по умолчанию) или `interior`. `system`: `masonry` или `steelGlass` (стальная остеклённая перегородка во всю стену; двери в ней — проёмы типа `door`).
- **Наружные стены перечисляй против часовой стрелки** (если смотреть сверху): линия `a→b` — наружная грань, тело стены лежит слева. Внутренние стены — по оси (`align: center`).
- `thickness`: по умолчанию 0.4 (наружные) / 0.12 (внутренние). `align`: `outer` · `center` · `inner`.
- `bottom`/`top` — абсолютные высоты. По умолчанию наружная стена идёт от земли (нижний этаж) до перекрытия следующего этажа или до `elevation + height + 0.3` на верхнем (там на неё ложится крыша, `roof.base` = этой высоте).
- Отделка снаружи `outside`: `stone`, `plinth`, `stucco` (тёмная), `render#rrggbb` (светлая штукатурка любого цвета), `wood` (вертикальные рейки на чёрной подложке) или любой материал; внутри `inside` (по умолчанию `plaster`).
- `plinth`: высота цоколя. `zones`: участки другой отделки `{ "from", "to" (м от точки a), "bottom", "top" (абсолютно), "finish" }`.
- Углы: облицовка сама заворачивает на внешних углах соседних наружных стен; `wrapStart`/`wrapEnd` задают это явно.
- Перегородку веди **до грани** соседней стены (или в её тело). Если конец не дошёл до стены меньше 0.6 м, он сам продлевается
  до неё — щель насквозь не остаётся; проёмы при этом не сдвигаются (`at` считается от исходной точки `a`). Так же
  замыкается угол: две стены под углом, обе не дошедшие до точки встречи меньше чем на 0.6 м, продлеваются до неё.
- Наружная стена выше плоской крыши за ней — это парапет: изнутри над кровлей он получает наружную отделку и металлический отлив.
  Верх стен всегда закрыт, `steelGlass` на уровне перекрытий и над потолком верхнего этажа получает глухую тёмную полосу.

## Проёмы — `openings`

```json
{ "id": "entry", "wall": "front", "type": "entryDoor", "at": 8.15, "width": 1.05, "sill": 0, "height": 2.3 }
```

- `at` — расстояние от точки `a` стены до края проёма; `sill` — низ проёма над полом этажа стены (по умолчанию: окно `window` — 0.9 м, двери, `glazing` и `hole` — 0, от пола); `height`, `width`.
- У наружного угла первые `thickness` метров стены заняты телом соседней стены: `at` ≥ толщина соседней стены + 0.1
  (и так же от конца `b`). Верх проёма (`sill + height`) не выше верха стены — его даёт `house_inspect` (`walls[].top`).
  Свободные участки стены для новых проёмов — `house_inspect` → `walls[].free`.
- `type`: `window` · `glazing` (витраж, толстый профиль) · `door` (внутренняя дверь: модель из каталога `house_doors` или гладкое полотно) · `entryDoor` (стеклянная входная) · `solidDoor` (глухая) · `hole` (пустой проём).
- Окна: `columns` (импосты), `transoms` (высоты горизонтальных перемычек от низа проёма), `curtain`: `none` · `full` · `left` · `right`, `curtainFraction`.
- Двери: `hinge` (`start`/`end` — сторона петель), `swing` (+1 — открывается влево от `a→b`, т.е. внутрь для наружных стен; −1 — вправо). Двери открываются в приложении (клик по двери или E), `open: true` — дверь показана открытой.
- **Межкомнатные двери из каталога** (`house_doors`): проём `type: door` + `model` (id модели, `porta-22`), `finish` (цвет серии,
  `cappuccino-veralinga`), `glass` (стекло модели, `mf`) и `leaf` — размер **полотна** `[ширина, высота]` (стандарт 0.6 / 0.7 / 0.8 / 0.9 × 2.0).
  Проём в стене считается из полотна сам (таблица каталога): ширина = полотно + 0.095, высота = полотно + 0.07 — задавай `leaf`,
  а не `width`/`height` (если задать только `width`, полотно подберётся под проём; нестандартное — предупреждение «под заказ»).
  Строится весь дверной блок: коробка 70 мм заподлицо со стороной открывания (`swing`), доборы до толщины стены, наличники 70 мм
  с двух сторон, петли (видны со стороны открывания), ручки. `hinge: start` — петли у края проёма, ближнего к `a` стены, `end` — у края к `b`.
  Без `model` — простая гладкая дверь.
- Вид двери `kind` (для моделей каталога; любая межкомнатная модель ставится любым способом):
  - `swing` (по умолчанию) — распашная; `leaves: 2` — двустворчатая (обе створки по `leaf`; активная с ручкой — у стороны `hinge`),
    проём = 2 × полотно + 0.004 + 0.095;
  - `sliding` — купе: полотно висит на направляющей на стене со стороны `swing` и уезжает вдоль стены к стороне `hinge`
    (`leaves: 2` — две створки разъезжаются), проём обрамлён доборами и наличниками; нужна свободная стена сбоку шириной с полотно;
    проём = полотно − 0.02 по ширине, + 0.035 по высоте;
  - `folding` — книжка: створки `leaf` 0.35 или 0.4 × 2.0, `leaves: 2` (одна книжка у `hinge`) или 4 (по книжке с каждой стороны),
    складываются в сторону `swing`; проём = створки + 0.085 по ширине, + 0.095 по высоте;
  - `portal` — портал: проём только обрамлён (доборы по откосам, наличники), без полотна; нужен `finish`, размеры — `width`/`height`.
- `lock: "wc"` — фиксатор для санузла под ручкой (поворотная кнопка изнутри, индикатор снаружи).

  ```json
  { "id": "d-bed", "wall": "p2", "type": "door", "at": 0.3, "model": "porta-22", "finish": "grey-veralinga", "glass": "mf", "leaf": [0.8, 2.0], "hinge": "start", "swing": -1 }
  ```

## Комнаты — `rooms`

```json
{ "id": "living", "name": "Гостиная", "level": "ground", "type": "living", "outline": [[0.4,0.4],[8,0.4],[8,8.2],[0.4,8.2]] }
```

- `outline` — многоугольник по внутренним граням стен (для смежных комнат — по оси перегородки, чтобы полы сошлись без щелей). Комнаты одного этажа **не должны перекрываться**.
- Пол этажа строится **целиком**, а не только под комнатами: под перегородками и дверными проёмами, в проходах между
  комнатами и в любой зоне внутри наружных стен, для которой ты не задал комнату (там пол `oak` и потолок снизу).
  Дыра в перекрытии бывает только над лестницей (`well`) и над комнатой второго света (`height`, см. ниже) — пустоту
  задавай высотой нижней комнаты, а не пропуском комнаты наверху.
- Комната даёт: плиту перекрытия с полом (`floor`, по умолчанию `oak`; санузлы/котельные — `tile`), потолок (`ceiling`), встроенные светильники (`downlights`: `auto` · `none`), пробу отражений (`probe`), мягкий свет, если в комнате нет явного источника.
- `height` больше высоты этажа = **второй свет**: над комнатой не должно быть комнаты верхнего этажа. Открытый край пола
  верхнего этажа (галерея) над вторым светом ограждается стеклом автоматически — везде, где на нём нет стены или твоего
  `railing` (свой `railing` ставь, если нужен другой стиль: авто-ограждение заполнит только оставшиеся промежутки).
- Над лестницей комнату верхнего этажа оставляй целой: проём в её полу вырежет лестница (`well`).
- `type`: `living, kitchen, dining, bedroom, bathroom, hall, corridor, wardrobe, utility, office, stair, garage, terrace, other`.

## Крыши — `roofs`

```json
{ "id": "main", "type": "gable", "outline": [[0,0],[14,0],[14,8.6],[0,8.6]], "base": 3.55, "pitch": 35, "overhang": 0.5, "material": "coping", "gable": "wood" }
```

- `type`: `flat` (любой многоугольник, `parapet` — высота парапета) · `shed` · `gable` · `hip` (по охватывающему прямоугольнику контура в системе крыши).
- Направление: `gable`/`hip` — конёк вдоль локальной X: при `rotation` 0 конёк идёт запад–восток, скаты смотрят на север и юг,
  фронтоны — на запад и восток; `rotation` 90 — конёк север–юг. `shed` — скат **поднимается в сторону `rotation`**:
  0 — высокая сторона на севере, 90 — на востоке, 180 — на юге.
- `base` — высота, на которую опирается крыша. **Не указывай его**: по умолчанию это верх наружных стен под контуром крыши
  (стены верхнего этажа заканчиваются на `elevation + height + 0.3`). Скатная крыша опирается на стены по их внутренней
  грани, свес `overhang` (одинаковый со всех сторон) опускается по уклону `pitch`. Реальные высоты карниза и конька —
  `house_inspect` → `roofs`. Если свес попадает в соседнюю более высокую комнату (второй свет), проверка скажет об этом.
- `thickness`, `material` (покрытие), `soffit` (подшивка), `gable` (отделка фронтонов: `wood` — вертикальная доска).

## Лестницы — `stairs`

```json
{ "id": "main", "type": "u", "from": "ground", "to": "upper", "start": [8.77, 6.75], "direction": 0, "width": 1.13, "going": 0.26, "risers": 19, "firstFlight": 11, "turn": "left", "gap": 0.07, "landing": 1.43 }
```

- `start` — низ первого марша по его оси; `direction` — направление подъёма первого марша (0 = +Z, 90 = +X).
- `type`: `straight` · `l` · `u`; `turn`: `left`/`right` — куда поворачивает второй марш; `firstFlight` — подступенков в первом марше; `landing` — глубина площадки.
- `style`: `floating_oak` (консольные дубовые ступени, стеклянное ограждение, подсветка) или `solid`.
- Консольным ступеням нужна стена: ставь марш вплотную к стене (≤ 0.15 м). Сторона марша или площадки без стены
  (или у стеклянной стены) получает сама стальной косоур, стеклянное ограждение с поручнем, а площадка — опоры.
- `well` — проём в перекрытии над лестницей: `auto` (по умолчанию) — вырезается сам там, где над ступенями меньше 2 м, открытые
  края ограждаются стеклом (кроме края схода и краёв у стен); `open` — без ограждения; `none` — не вырезать. Если между проёмом
  и стеной остаётся полоса перекрытия уже 0.6 м, проём доводится до стены (иначе это «висящая балка» в холле).
  **Контуры комнат под лестницу не вырезай** — комната верхнего этажа остаётся целой, потолок над ней тоже.
- Габарит маршей, проём и линия схода — `house_inspect` → `stairs`. Сход с лестницы должен попадать в комнату верхнего
  этажа, а не в стену.
- **Лестничная клетка на несколько этажей** — на каждый этаж своя лестница (`from`/`to` соседних этажей) с теми же `start`,
  `direction`, `turn`, `width`: верхняя стоит точно над нижней. Её марши висят над проёмом нижней лестницы — `solid` там сам
  строится плитой под ступенями (а не массивом до пола), стеклянное ограждение проёма у первой ступени верхнего марша не
  ставится.
- После сборки дом проверяется «ногами»: над каждой ступенью и площадкой должно быть ≥ 2 м до чего угодно (перекрытия,
  другой лестницы, балки), перед первой ступенью и на сходе — 0.8 м свободного пола шириной с марш. Нарушение придёт в
  `issues` с точкой и тем, что мешает.

## Лифты — `lifts`

```json
{ "id": "L1", "model": "k600l-mrl", "load": 1000, "position": [3.0, 11.2], "rotation": 180, "from": "b", "to": "l3", "cabin": "sl-1136", "door": "sl-8055" }
```

- Лифты каталога GLZ / NBSL (`house_lifts`): пассажирские `k600-mr-rear` / `k600-mr-side` (машинное помещение на крыше), `k600l-mrl`
  (без машинного), панорамные `k600g-mr` / `k600g-mrl` (полукруглая или ромбовидная стеклянная шахта), грузовые `h700-*`, автомобильный
  подъёмник `h700-car-*`. Все размеры — из таблицы модели по `load` (кг), `speed` (м/с; задаёт оголовок и приямок) и, если у
  грузоподъёмности несколько кабин, `car` [ширина, глубина] в мм (носилочный лифт больницы — `car: [1100, 2100]`, 1000 кг).
- `position` — **середина дверей на передней грани шахты** (со стороны холла), `rotation` — куда смотрят двери (0 = +Z, 90 = +X).
  Шахта лежит за этой точкой: ширина и глубина — шахта из таблицы плюс стены 0.2 м (`wall`). Ставь её за стеной холла или в
  нише; **стены шахты строятся сами — не рисуй их** (или `shaft: "none"`, если рисуешь сам). `shaft: "glass"` — стеклянная
  шахта (панорамные по умолчанию).
- `from` / `to` — нижняя и верхняя остановка (по умолчанию все этажи), `skip` — этажи без дверей. Под нижней остановкой —
  приямок (PD), над верхней — оголовок (OH): шахта поднимается над крышей сама, у MR-лифтов на ней машинное помещение.
  Перекрытия и потолки на пути шахты вырезаются сами — **контуры комнат не вырезай**.
- `cabin` — дизайн кабины, `door` — этажная дверь, `panel` / `call` — пост в кабине и вызывная панель (все id — `house_lifts`);
  `side` — сторона противовеса (`left`/`right`, у моделей с боковым противовесом); `parked` — этаж, где стоит кабина;
  `open: true` — двери на этом этаже открыты.
- Лифты работают в прогулке: кнопка у дверей вызывает кабину, пост в кабине открывает меню этажей, кабина едет со скоростью
  модели и везёт стоящего в ней, двери ждут, пока кто-то стоит в проёме.
- Перед дверями на каждой остановке нужно ≥ 1.5 м свободного холла. Пересечения шахты со стенами, лестницами и мебелью,
  двери в стену и шахта за пределами здания приходят в `issues`. Реальные числа (шахта, кабина, дверь, приямок, верх шахты,
  точка перед дверями) — `house_inspect` → `lifts`.

## Элементы — `elements`

Вид элемента — в поле `type`: `box` · `beam` · `platform` · `column` · `railing` · `pool`.

```json
{ "id": "terrace", "type": "platform", "min": [0, 0, -3], "max": [6, 0.3, 0], "material": "stone", "top": "deck_boards" }
{ "id": "belt", "type": "box", "min": [0, 3.3, -0.1], "max": [12, 3.6, 0.3], "material": "stucco", "bottom": "soffit", "cap": "coping" }
{ "id": "rail", "type": "railing", "path": [[0, -3], [6, -3]], "y": 0.3, "height": 1.0, "style": "glass" }
```

- `box`/`beam`/`platform`/`column`: `min`, `max` (абсолютные `[x,y,z]`), `material` (бока), `top`, `bottom` (материалы
  верхней и нижней грани; `"none"` — без грани), `cap` — **имя материала** отлива сверху (`"coping"`), его размеры
  `capHeight`, `capOverhang` — отлив накрывает **весь верх** элемента (для газона или мощения сверху используй `top`, а не `cap`). Так делаются пояса, козырьки, парапеты, террасы, ступени, колонны. Для газона на элементе —
  `top: "lawn"`.
- `railing`: `path` (точки на плане), `y` (низ, абсолютный), `height`, `style`: `glass` (стеклянные панели с профилем) · `glass_oak` (цельное стекло с дубовым поручнем) · `metal`.
- `collide: false` — без коллайдера.
- Дверь или витраж до пола в наружной стене выше земли (балкон, терраса второго этажа) должны выходить на опору — `platform`
  с верхом на уровне пола; иначе проверка предупредит «дверь в обрыв».

### Бассейн — `pool`

```json
{ "id": "pool", "type": "pool", "min": [25.9, -0.6, 0.7], "max": [29.0, 0.88, 6.86], "glass": ["north"] }
```

- `min`/`max` — чаша **по внутренней грани** (зеркало воды): `max.y` — борт (уровень террасы/земли вокруг), `min.y` — дно
  (глубина обычно 1.2–1.6 м). Непрямоугольный — `path` (выпуклый контур) + `y` (борт) + `height` (глубина).
- Бассейн сам вырезает себя из земли, из `platform`/`box`, верх которых на высоте чаши, и из пола комнаты (крытый
  бассейн). Ставь его **в террасу** (`platform` с верхом = `max.y`) или в землю (`max.y` ≈ 0–0.1); вокруг — камень борта 0.3 м.
- `glass` — стеклянные стороны: `north`/`east`/`south`/`west` или номера рёбер `path`. Имеет смысл, где чаша выше того, что
  перед ней: торец приподнятой террасы над настилом — видна толща воды.
- `material` — облицовка чаши (по умолчанию голубая мозаика `tiles_mosaic_wall#8fd0ee`), `top` — камень борта
  (`travertine_tiles`), `outside` — стенки чаши снаружи, если она стоит выше земли, `water` — цвет воды `#rrggbb`,
  `style: "overflow"` — вода вровень с бортом (переливной).
- Шезлонги — предмет `sun_lounger` (изголовье к +Z). `house_inspect` → `elements` даёт борт, уровень воды, дно и габарит с бортом.

## Предметы — `items`

```json
{ "id": "sofa", "model": "sofa", "level": "ground", "position": [3.4, 0, 4.3], "rotation": 90, "params": { "length": 2.8, "fabric": "linen" } }
```

- `position`: X/Z на плане, Y — над полом `level` (без `level` — абсолютная высота). `rotation` — куда смотрит перед предмета (0 = +Z, 90 = +X).
- Встроенные вещи ставятся спинкой к стене: точка — у стены, перед — в комнату. Подвесы и люстры — точка на потолке (Y = высота этажа).
- Модели, параметры и **реальные размеры** — `house_catalog` (по `category` или `id`): `size` = [ширина поперёк фасада,
  глубина вдоль `rotation`, высота], `fromOrigin` — сколько предмет занимает от точки `position` вперёд/назад/влево/вправо,
  `note` — где точка (у задней стороны, на потолке, на стене) и куда идёт длинная сторона (у `dining_table` и `bed` — вдоль
  `rotation`, у `sofa` и `kitchen_island` — поперёк). Проверка после правки скажет, если предмет заходит в
  стену, закрывает проём, стоит в проходе у двери (0.8 м) или пересекается с другим. Мебель: `sofa, armchair, lounge_chair, chaise_longue, dining_chair, bar_stool, bench, round_table, wire_table, dining_table, desk, wardrobe, fluted_cabinet, cubby_shelf, tv_console, media_wall, nightstand, bed`; кухня и ванная: `kitchen_base, tall_units, kitchen_island, vanity, toilet, bathtub, shower, towel_rail`; свет: `pendant_globe, linear_pendant, chandelier, table_lamp, floor_lamp, downlight, led_slot`; стены и текстиль: `slat_panel, artwork, mirror_round, rug, drapes, panel`; декор: `vase, books, twigs`; растения: `plant_tree, plant_grass`; прочее: `boiler, washer_stack, rattan_lounge_chair, bistro_set`.

- **Библиотечные модели** (сканы Poly Haven и модели из Blender, 75 шт.) — реалистичнее процедурных, но фиксированного
  размера. Список с размерами и слотами — `house_catalog` (параметры вида `upholstery=linen_rough#c8c0b3`). Слоты
  материалов: библиотечный материал, `#rrggbb` (подкрасить родной) или `original`. Точки опоры: мебель — центр на полу
  (кровати — центр изголовья у стены), подвесы — точка на потолке, настенные (`poster_frame`, `wall_sconce_black`,
  `wall_clock_modern`…) — центр задней стороны: Y = высота центра над полом. Примеры: `sofa_modern`, `bed_modern`,
  `lounge_chair_leather`, `dining_table_round`, `sideboard_slatted`, `shelf_cubes`, `pendant_industrial`,
  `vase_white_round`, `plant_ficus`, `fire_pit`, `bistro_set_garden`. Источник списка — `tools/assets/catalog.json`.

## Свет — `lights`

`{ "id": "chandelier", "type": "point", "position": [7.06, 4.4, 2.2], "color": "warm", "intensity": 1.3, "range": 9, "shadows": true }`

- `type`: `point` · `spot` (`target`, `angle`). `color`: `warm` · `neutral` · `cool` · `fire` · `#rrggbb`. С `level` высота считается от пола этажа.

## Точки презентации — `views`

```json
{ "name": "Гостиная", "type": "walk", "position": [4.2, 0.3, 3.5], "yaw": 45, "pitch": -5 }
{ "name": "Фасад", "type": "orbit", "yaw": 30, "pitch": 10, "distance": 26 }
```

- Ключ точки — `name` (не `id`). `type`: `walk` · `orbit`.
- `walk`: `position` — **абсолютная** точка ног `[x, y, z]` (y = отметка пола этажа), `yaw` — куда смотрим, `pitch` — наклон (минус — вниз).
- `orbit`: `yaw` — откуда смотрим (0 — с юга), `pitch`, `distance` — ракурсы вокруг дома. Без них приложение ставит стандартные.

## Участок — `site` с `landscape: "natural"`

Дом не закончен без участка: после мебели сделай участок инструментом **`house_site`**. Без аргументов он покажет
границы участка, входные двери и куда они смотрят, сторону улицы, дорожки, которые генератор проложит сам, высоты земли
и словарь типов. Правки: `set` — настройки, `upsert` — добавить/изменить элементы списков по `id` (меняются только
переданные поля), `remove` — удалить по `id`. Проверяй: `house_render` `mode: "site"` (генплан сверху) и `orbit`.

Сад строится **по замыслу**: ты задаёшь линии и стиль, генератор сам раскладывает рельеф, газон, растения, камни и воду
(одинаково при каждой сборке). Дом стоит на ровной площадке на отметке 0, рельеф — вокруг.

```json
{ "set": { "landscape": "natural", "plot": [-15, -25, 30, 22], "planting": { "style": "garden" },
           "terrain": { "slopeAzimuth": 0, "grade": 0.04 }, "fence": ["north", "east", "south", "west"], "street": "south" },
  "upsert": {
    "areas":   [{ "id": "patio", "type": "paving", "outline": [[0, 10], [6, 10], [6, 14], [0, 14]] },
                { "id": "drive", "type": "asphalt", "outline": [[12, -25], [15.5, -25], [15.5, -4], [12, -4]] },
                { "id": "park",  "type": "parking", "outline": [[16, -12], [28, -12], [28, -4], [16, -4]] }],
    "paths":   [{ "id": "garden", "path": [[3, 14], [3, 18], [-8, 19]], "width": 1.0, "style": "stepping" }],
    "hedges":  [{ "id": "h1", "path": [[-15, -2], [-2, -2]], "height": 1.2 }],
    "objects": [{ "id": "alley", "type": "tree", "species": "birch", "path": [[-12, -22], [-12, -6]], "spacing": 5 },
                { "id": "lamps", "type": "bollard", "path": [[1.2, -1], [1.2, -24]], "spacing": 4 },
                { "id": "b1", "type": "bench", "at": [-6, 8], "rotation": 90 },
                { "id": "t1", "type": "tree", "species": "maple_red", "at": [-8, 14] }],
    "beds":    [{ "id": "front", "outline": [[-6, -4], [-1, -4], [-1, -1.5], [-6, -1.5]], "style": "perennial", "flowers": ["salvia", "lavender"] }] } }
```

- `plot` — участок (линия забора) `[xmin, zmin, xmax, zmax]`; по умолчанию дом плюс 18 м во все стороны. Дом внутри.
- **Дорожка ко входу прокладывается сама** (`approach: "auto"`): от каждой входной двери (`entryDoor` первого этажа) к
  улице — сначала прямо от двери, потом к стороне `street` (по умолчанию — куда смотрит вход), вокруг дома, если улица
  позади. Если к двери уже подходит твоя дорожка или площадка, своя не нужна. `approach: "none"` — без авто-дорожек.
- `planting.style`: **`garden`** — газон, у забора полоса кустарников, цветы только в клумбах `beds` (обычный участок
  у дома); `lawn` — только газон и клумбы; `perennial` — цветущий миксбордер везде, где не газон (газон — полосы вдоль
  дорожек шириной `planting.lawn`); `meadow` (луговой), `shade` (папоротники, хосты), `rock` (рокарий). `flowers` —
  акцентные цветы: `salvia`, `lavender`, `lupin`, `daisy`, `phlox`, `yellow`, `orange`. `density` 0.3–1.5.
- `terrain`: склон поднимается в сторону `slopeAzimuth` (0 = север) на `grade` метров на метр (0.05–0.1 — заметный
  склон), `relief` — высота мягких неровностей. Без `terrain` участок почти ровный.
- `areas` — площадки с твёрдым покрытием, земля под ними выравнивается: `paving` (мощение: патио, площадь у входа),
  `asphalt` (проезд), `parking` (асфальт с разметкой мест `stall` [ширина, глубина], по умолчанию 2.5×5 м, вдоль
  длинной стороны; при глубине ≥ 15.5 м — два ряда с проездом), `gravel`, `deck` (настил), `rubber` (детская площадка),
  `lawn` (ровный газон). `outline` — многоугольник; у дома площадка на отметке 0, дальше — на высоте земли в её центре
  (`y` — задать самому); `material` — своё покрытие (любой материал, можно `имя#rrggbb`). Бордюры у мощения и асфальта
  ставятся сами. Под дом площадку не заводи — начинай у стены.
- `paths` — дорожки: `path` — осевая линия (углы сглаживаются), `width`, `style`: `stepping` (плиты-ступени в газоне),
  `paving`, `gravel`, `asphalt`, `deck`. На площадках дорожка не рисуется — площадка и есть дорожка.
- `hedges` — стриженые живые изгороди вдоль ломаной `path`: `height` (0.5 — бордюр, 1–2 — изгородь), `width`.
- `objects` — вещи на участке: `tree` (`species`: `oak`, `birch`, `spruce`, `maple_red`; `scale`), `shrub` (куст),
  `boulder` (валун), `bench` (скамейка, сиденьем в сторону `rotation`), `bollard` (низкий фонарь-столбик),
  `garden_lamp`, `stone_lantern` (светятся), `bridge` (от `at` до `to` через ручей). Одиночный — `at`; **ряд** (аллея,
  фонари вдоль дорожки, кусты вдоль забора) — один объект с `path` и `spacing` (м между соседями). Деревья ставь
  не ближе 3 м от стен.
- `beds` — клумбы многоугольником `outline` со своим `style` и `flowers`.
- `streams` — ручьи: `path` — русло **от истока к устью** (исток выше по склону), `width`, `depth`; каскады ставятся
  сами на перепадах ~0.5 м (свои — `cascades: [[x, z], …]`). Дорожка через ручей — только по мосту `bridge`.
- `fence` — стороны с забором: `north`, `east`, `south`, `west`; где к забору подходит дорожка или площадка —
  калитка/въезд (разрыв) делается сам. `trees`: `auto` — лес вокруг участка, `none` — без него.
- Высоты: `house_site` без аргументов показывает землю (мин/макс, углы участка) и уровни площадок; `house_render`
  `walk` снаружи дома без `level` ставит камеру на землю.
- Низкое солнце (`sunElevation` < 15) — длинные тени: каждое дерево затеняет газон на 4–10 своих высот.

## Материалы

Любой материал можно окрасить: `имя#rrggbb` — например, светлый фасад `render#e9e4da`, серый `render#b8b8b4`,
тонированное дерево `oak#8b6a4f`. `stucco` — тёмная антрацитовая штукатурка, `render` — светлая.

**Библиотека реалистичных материалов** (сканы Poly Haven, CC0, реальный масштаб рисунка) — 176 штук по категориям:
полы (`floor`), плитка и камень (`tile`), стены (`wall`), ткани (`fabric`), кожа (`leather`), ковры (`carpet`), шпон и
дерево мебели (`wood`), фасады (`facade`), кровля (`roof`), металл (`metal`), мощение (`paving`), террасная доска
(`deck`), грунт участка (`ground`). Полный список с русскими названиями — `house_materials` (раздел `library`).
Примеры: пол `parquet_herringbone`, стена `plaster_white`, фасад `brick_red` или `cladding_cedar`, кровля
`roof_clay_tiles`, дорожка `paving_herringbone_grey`. Материалы с серой основой (ткани, краски, микроцемент) задуманы
для окраски: `velvet#6b4f3a`, `paint_smooth#dfe6e1`. Источник списка — `tools/assets/catalog.json`.

Базовая палитра (отделка и мебель): `stone, plinth, stucco, wood, plaster, ceiling, oak, oak_light, walnut, tile, tile_dark, marble, travertine, porcelain, step_riser, gravel, paver, coping, soffit, frame, steel, black_metal, brass, chrome, glass, gloss_white, linen, boucle, sage, terracotta, charcoal, bedding, leather, leather_white, rug, rug_dark, towel, ceramic, stoneware, mirror, led`.

## Проверка

`issues` в ответе на каждую правку (и `house_validate`) — ошибки и предупреждения на русском с путём к элементу
(`openings/entry: проём выходит за стену…`). Две группы: проверка документа (ссылки, пересечения комнат, размеры) и проверка
построенного дома по реальной геометрии (мебель, двери, проёмы, крыши, лестницы, замкнутость контура). Исправляй их по ходу.
