# Textured decors the casegoods collections need (for the decor texture wave)

Each finish role that uses one of these has a provisional plain colour (`door_enamel_whitey#…`, the decor's mean
colour) until the texture exists. Format per line: name as the catalogue writes it — collections and roles — swatch page
(PDF page, `tools/casegoods/gen/catpage.py` crop) — character — grain direction; provisional colour.
