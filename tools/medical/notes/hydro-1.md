# hydro-1 — notes

Generators: `tools/medical/gen/h1_*.py` + `h1lib.py` (each writes only its own devices' design files).
Tub technique: outer skirt = `loft` with `caps: false` (tapered/bulging sides) or a ring `slab`; inside it a ring `slab`
of vertical inner walls + a basin floor, so the basin is open and visible from above; the rim = a ring `slab` (plan
outline with the basin hole) with large edge rounding `r` so it reads domed; water = a thin `acrylic` slab.

Engine notes: a solid part (box/slab/lathe with caps) at rim height closes the basin — every skirt, seam and rim roll

world axes (not along the tilted face) — place such rows one by one.
